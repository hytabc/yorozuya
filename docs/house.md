# 房屋使用与维护

入口为顶部“更多 → 房屋”。每个账号一套房屋，游客可浏览公开家具及房屋分享链接。

## 使用

- 我的房屋：选择家具后点击房间或“放在中央”；也可把家具卡拖入画布。选中家具后调整 X/Y/Z、旋转、部位颜色或整套配色。拖动模式下无效位置显示红色，松开后恢复原位置。
- 画布：视角按钮旋转、缩放及重置，滚轮缩放、右键或双指平移；访客可直接拖动画布调整视角。
- 示例布置：可选客厅、卧室、书房、厨房、卫浴；替换现有布局前确认，并可撤销。
- 家具工坊：选择 16³/32³/64³ 网格，用放置、删除、着色和三轴镜像制作家具。切片支持内部结构编辑，也可输入精确坐标。保存到账号后在“我的作品”中发布，或复制已有家具制作自己的版本。
- 房屋修改会先写账号隔离的 IndexedDB 草稿，再串行保存到云端。断网保留草稿；版本冲突停止同步，可导出当前草稿、重新载入云端并选择恢复。
- 家具 JSON 可导入导出；房屋草稿导出包含引用模型，便于保存本次编辑。房屋草稿恢复通过同一浏览器的恢复提示进行。
- 开启分享后，每次成功云端保存都会更新访客页面。关闭分享使旧链接失效，重新开启生成新链接。点赞、留言需要登录。
- 自定义纹理支持 PNG/JPEG、单张最多10 MB。审核前只给上传者预览；公开房屋回退到底色。删除或驳回后公开 URL 失效。

## 审核与部署

监管台“房屋管理”可预览和隐藏房屋、家具；“图片管理 → 房屋纹理”负责图片审核。权限沿用超级管理员、管理员和风纪委员，未放宽统计权限。

新表在后端启动时创建，并补充官方家具目录。更新需同时部署前端构建、后端以及两层 Nginx 配置；家具数据接口上限8 MiB，纹理上传入口11 MiB，其余默认1 MiB保持。

房间最多128件家具、累计100万占用体素。初版不包含实时联机、公共房屋排行榜或第三方登录。
