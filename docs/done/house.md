# 房屋使用与维护

入口为顶部“更多 → 房屋”。每个账号一套房屋，游客可浏览公开家具；参观房屋需要登录，房屋默认私密。

## 使用

- 我的房屋：选择家具后点击房间或“放在中央”；也可把家具卡拖入画布。选中家具后显示 X/Y/Z 三轴箭头；切换“移动”拖动箭头，或使用轴向加减按钮与数值输入。直接拖家具改变地面位置，保留原高度。无效位置显示红色，松开恢复；Esc、取消触控或失焦均取消拖动。旋转按90°步进，大小支持50% / 100% / 200%，缩放后的重叠与边界由前后端共同校验。
- 画布：切换“视角”后左键或单指旋转，滚轮/捏合缩放、右键或双指平移；下方按钮可旋转、缩放及重置。拖动家具时暂停相机。首次进入按账号展示操作教程，也可随时点击“操作帮助”。
- 示例布置：可选客厅、卧室、书房、厨房、卫浴；替换现有布局前确认，并可撤销。
- 家具工坊：新作品选择16³/32³网格，用放置、删除、材质涂刷、吸管与三轴镜像逐块拼搭。内置木材、金属、玻璃、塑料、布料、石材、陶瓷、发光八种材质，每个调色板组合分别设置材质与自由颜色，最多64种组合及8192块。切片支持内部结构编辑，也可输入精确坐标，支持撤销与重做。渲染按材质批量实例化，只绘制可见表面。
- 账号家具库：保存后在“我的作品”中重新编辑、摆放、复制、删除或发布。公开家具可收藏、复制到自己的账号，再改造；作者更新或取消分享不影响已复制的独立副本。房屋引用不可变家具版本，修改库中原件也不会改变已有摆放。
- 房屋修改会先写账号隔离的 IndexedDB 草稿，再串行保存到云端。断网保留草稿；版本冲突停止同步，可导出当前草稿、重新载入云端并选择恢复。
- 家具 JSON 可导入导出；房屋草稿导出包含引用模型，便于保存本次编辑。房屋草稿恢复通过同一浏览器的恢复提示进行。
- 保存与发布：保存房屋和家具只更新私人草稿。房屋点击“开放参观”发布完整布局快照，此后通过“更新展示”发布新版本，保持原链接；家具点击“发布到家具库 / 更新分享”更新公开版本。发布携带当前revision，其他页面更新后返回409，避免误发布未检查的版本。预览自己旧分享的家具时，先载入最新草稿，再确认发布。
- 参观：在“参观”标签查看房主开放的小屋，也可使用分享链接或创作者主页进入。访客看到已确认发布的房屋名称、布局、家具版本及其展示资料，只能调整视角；可返回自己的房屋、继续参观、点赞或留言。关闭参观使列表与旧链接失效，重新开放生成新链接。屏蔽房屋或家具、撤回纹理的审核语义仍实时生效。
- 自定义纹理支持 PNG/JPEG、单张最多10 MB。审核前只给上传者预览；公开房屋回退到底色。删除或驳回后公开 URL 失效。

## 审核与部署

监管台“房屋管理”可预览和隐藏房屋、家具；“图片管理 → 房屋纹理”负责图片审核。权限沿用超级管理员、管理员和风纪委员，未放宽统计权限。

新表在后端启动时创建，并补充官方家具目录。SQLite轻量迁移增加房屋和家具发布快照字段，保留升级前已经分享的外观；新增收藏关系表。旧版64³或较大家具仍能读取、复制和保留尺寸编辑，不能继续扩大超限数据；新作品按上述限制校验，旧色板未指定材质时沿用原有渲染。更新需同时部署前后端；家具数据接口上限8 MiB、纹理上传11 MiB及两层Nginx配置保持。

房间最多128件家具、累计100万占用体素；缩放使用整数或半格占用校验。参观列表按发布时间分页，不包含实时联机、排行榜或协同装修。

## 接口补充

- `Slot.material` 可选上述八种材质；旧数据缺省为原色材质。`Placement.scale` 缺省为1，可取0.5、1、2。
- `PATCH /api/house/room/share` 和 `PATCH /api/house/furniture/{id}/publish` 接收 `{enabled, revision?}`；新前端发布时提交revision，撤回无需先保存草稿。
- `GET /api/house/rooms` 为登录后参观列表；`GET /api/house/visit/{shareId}` 及其留言列表同样要求登录。
- `GET /api/house/furniture?favorites=true` 查询个人收藏；`PUT/DELETE /api/house/furniture/{id}/favorite` 收藏/取消。
- `POST /api/house/furniture/{id}/copy` 接收 `{versionId?}`，复制到当前账号，返回独立家具和不可变版本；他人只能复制当前公开、未屏蔽的分享版本。
- 列表沿用 `{total,page,page_size,items}`；写操作及房屋读取沿用邮箱验证闸门。后台审核及私有媒体访问保持原权限。
