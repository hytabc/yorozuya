【四项改造需求】

1) NPC 立绘卡（LifeScene.vue）
- 当 dialogueVisible 为 true 时，在场景中央偏左（dialogue-overlay 上方区域，z-index 低于对话浮层）渲染当前 NPC 的「立绘卡」：npcPortrait 大图（约 120-140px，圆角 16px 或圆形）+ 下方名字标签；参考死 CSS .npc-sprite 的位置（left:50%; top:45%），可微调避免压住气泡
- 入场动画：opacity 0→1 + translateY(12px→0)，300ms ease-out；切换 NPC（currentNpcId 变化）时重新播放入场
- 说话者明暗（galgame 经典）：speech.from === 'npc' 时立绘全亮（opacity 1）；speech.from === 'player' 时立绘变暗（opacity .55 + filter: saturate(.6)），过渡 250ms
- 待机呼吸：轻微 translateY ±4px，3s infinite alternate
- dialogueVisible 变 false 时淡出移除（用 Vue <Transition>）

2) 气泡入场 + 打字游标（LifeScene.vue）
- 每条新发言开始时 .current-speech 播放 pop-in：scale(.96)→1 + opacity 0→1，180ms。实现建议：watch speech.typing 的上升沿（false→true）时自增一个 speechEpoch ref，作为 .current-speech 的 :key，动画 class 直接写在元素上（key 变化触发重挂载即播动画）
- 打字游标：speech.typing 为 true 时，气泡文字末尾渲染一个闪烁游标 ▍（CSS animation 1s step 闪烁，颜色跟随气泡文字色）
- 不要破坏 @click="playback.complete"、缩略图条件渲染和「点击显示全文」small

3) 选项/动作按钮 stagger 入场（LifeScene.vue）
- showChoices 变 true 时，.reply-option 按钮依次浮现：opacity 0→1 + translateY(8px→0)，每个延迟 i×70ms（第 6 个起不再增加延迟），总时长 250ms。实现建议：watch showChoices 上升沿自增 choicesEpoch，作为 .reply-options 容器的 :key，按钮上用 :style="{ transitionDelay: Math.min(i,5)*70 + 'ms' }" 或 CSS animation-delay
- 动作页签同理：replyTab 切换到 'actions' 时 .action-option 按 i×50ms stagger
- 注意按钮 disabled 态不受动画影响（opacity 由 disabled 样式优先）

4) 数值变化反馈（LifeCharPanel.vue + LifeScene.vue）
- LifeCharPanel.vue：watch stats 的每个 key（mood/energy/social/explore），值变化时：
  a) 该行 .stat-row 背景闪烁一次：增加为正 → 闪 #e5f3eb（绿），减少 → 闪 #f9e8e8（红），600ms 内淡出回透明
  b) 数字右侧飘出 delta 文本（如 +3 / −2，减号用全角负号或 -，正绿 #237a57 / 负红 #c0392b），向上浮 16px 同时淡出，900ms，然后消失。可用绝对定位小 span + 每次变化自增 epoch 作为 :key 重触发
- LifeScene.vue：watch bondDelta，>0 时在 NPC 头像（.npc-identity）旁飘出「好感 +N」小气泡：从头像上方浮现，向上浮 24px 淡出，1.2s；.reply-tabs 里原有的静态小字保留不动（它有 role="status" 的无障碍作用）
