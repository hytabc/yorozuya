# 万事屋内容整合、交流大厅与委托分类改版 PRD

版本：1.0
日期：2026-09-20

## 1. 背景与目标

站内页面逐渐增多，顶部导航已经平铺到十个以上入口，新用户难以判断各功能的归属。本期把现有页面收进六个「大厅」，并新增「交流大厅 · 疑难解答区」，同时重整委托分类。

成功标准：

- 顶部导航按六个大厅分组，任何页面都能一眼看出属于哪个大厅。
- 用户可以在疑难解答区发帖、盖楼、采纳最佳回答，并可按子版块筛选、分页浏览。
- 委托分类收敛到六个语义明确的选项，历史委托被正确归并。

## 2. 信息架构（六个大厅）

| 大厅 | 包含页面 | 说明 |
|---|---|---|
| 委托大厅 | 委托大厅 `/`、我的委托 `/mine` | 经典大厅：发布与接取委托 |
| 交流大厅 | 留言板 `/board`、疑难解答 `/talk` | 留言板（留言 + 评论）与盖楼式问答并存 |
| 游戏大厅 | 虚拟人生 `/life`、糖霜世界 `/frost` | 站内游戏 |
| 分享大厅 | 故事会 `/stories`、地图推荐 `/maps` | 用户创作与推荐 |
| 交友大厅 | 交友厅 `/friends`、砂糖社 `/sugar` | 交友与关系 |
| 官方大厅 | 成员名录 `/staff`、公告中心 `/announcements`、版本更新 `/versions` | 官方信息 |
| 更多（管理） | 监管台/审核台 `/admin`、运营台 `/operations` | 仅对应角色可见 |

规则：

- 导航分组是**纯前端**行为，不改变任何既有路由与页面。
- 大厅内可见条目只剩一条时渲染为直达链接；为空时整组隐藏。可见性沿用原守卫：`/life` 需身份确认后（`ready` + 登录）才显示，其余登录态页面按 `isLoggedIn`。
- 导航归属集中在 `frontend/src/navigation.js`（纯数据、可单测）；桌面端用下拉、移动端用折叠分组。
- 个人设置 `/profile` 仍走右上角用户菜单，不进入大厅。

## 3. 交流大厅 · 疑难解答区（`/talk`）

### 3.1 功能

- 游客可浏览；登录后可发帖、回复、匿名发布。
- **子版块**：萌新求助、技术疑难、VRC 相关、资源分享、闲聊水区、其他。
- **盖楼**：主楼（1 楼）+ 楼层，楼层号从 2 起递增，删除楼层不回收楼层号。
- **分页**：帖子列表与楼层列表均分页（默认每页 20，上限 50）。
- **采纳最佳回答**：仅楼主可标记/取消，列表与详情显示「已解决」。
- **匿名**：发帖与回复均可匿名，作者对本人与管理员组可见，其余人只看到「匿名用户」。

### 3.2 数据表

- `talk_threads`：`board`（子版块 key）、`title`、`content`、`user_id`、`is_anonymous`、`accepted_reply_id`（不建外键，删除楼层时由业务清空）、`last_reply_at`、`created_at`。
- `talk_replies`：`thread_id`、`user_id`、`is_anonymous`、`floor`、`content`、`created_at`。

### 3.3 接口

| 方法与路径 | 权限 | 用途 |
|---|---|---|
| `GET /api/talk/threads?board=&search=&page=&page_size=` | 公开 | 帖子列表（按最后回复时间倒序） |
| `GET /api/talk/threads/{id}?page=&page_size=` | 公开 | 主楼详情 + 楼层分页 |
| `POST /api/talk/threads` | 登录 | 发帖 |
| `POST /api/talk/threads/{id}/replies` | 登录 | 盖楼（楼层号行锁自增） |
| `POST /api/talk/threads/{id}/accept` | 楼主 | 采纳/取消采纳最佳回答 |
| `DELETE /api/talk/threads/{id}` | 作者/管理员组 | 删除帖子（级联楼层） |
| `DELETE /api/talk/replies/{id}` | 作者/管理员组 | 删除楼层 |

- 限流桶 `talk-post`：发帖与回帖共用，每用户 20 次 / 10 分钟。
- 删除权限沿用留言板口径：作者本人或超管/管理员（`staff`）。
- 埋点页面 key `talk`；事件 `talk.create` / `talk.reply` / `talk.accept` / `talk.delete`。

## 4. 委托分类改版

新分类：**萌新上路、心理倾听、技术疑难、VRC寻图、搭子召集、其他委托**。

- 前端 `frontend/src/constants.js` 的 `CATEGORIES` 与后端 `main.py` 的 `TASK_CATEGORIES` 白名单保持一致，创建委托时后端校验（不合法返回 422「委托分类不正确」）。
- 历史值迁移（`migrate_schema()`，幂等）：倾听→心理倾听；解惑/建模→技术疑难；聊天/陪玩/陪睡→搭子召集；拍摄/其他→其他委托；其余未知值一律归「其他委托」。

## 5. 验收标准

1. 顶部导航只出现六个大厅（+ 按角色出现的「更多」），页面归属与第 2 节一致；游客看不到游戏大厅与交友大厅。
2. 疑难解答区：发帖后楼层号从 2 递增；切后台/翻页数据正确；楼主可采纳，非楼主采纳返回 403；删除被采纳的楼层会清空「已解决」。
3. 匿名帖在游客与他人视角显示「匿名用户」，作者本人仍看到自己的昵称。
4. 使用旧分类（含任意未知值）的历史委托在升级后全部落到新分类；创建委托传非法分类返回 422。
5. 移动端导航按大厅折叠分组展示，不出现横向溢出。

## 6. 非目标

- 不做大厅聚合落地页（导航分组即可）。
- 疑难解答区暂不做点赞、举报、富文本、@ 提醒、楼层内嵌套回复与附件上传。
- 详情用弹窗而非独立路由，暂不提供可分享的单帖 URL。
