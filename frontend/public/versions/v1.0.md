### 💰 积分与评价系统

**积分机制**
- 双口袋设计：终身积分（公开）+ 钱包积分（私密）
- 委托规模（small/medium/large）× 分类系数 = 基础积分
- 完成委托先发60%基础积分，评价后按星级结算尾差
- 防刷规则：同对衰减、日上限60分、新号折扣

**评价系统**
- 0-5星半星11档双向评价
- 7天窗口、双盲制、24小时内可改一次
- 贝叶斯平滑聚合分（10×4.0+Σ）/(10+n)
- 差评可申诉，撤销后重算积分

**等级与特权**
- Lv1-10由终身积分推导
- 接单上限 = max(管理员设置, 2+Lv//3)
- 悬赏上限 = Lv×20
- Lv3起可发悬赏，评分过低受限

### 📅 每日任务与官方委托

**每日任务**
- 固定5项：发布≥30字 +2、完成 +4、评价 +1、分享 +1、全清 +2
- 按Asia/Shanghai 0点刷新
- 需手动领取积分

**官方活跃委托**
- 系统账号发布，全局共享最多3个
- 每4-8小时刷新1个
- 接单人完成站内动作后自动发积分
- 不参与评价

### 🏆 成就与排行榜

### 🛡️ 安全加固

**令牌版本控制**
- User.token_version字段，JWT载荷含ver
- 改密/重置密码时token_version += 1，旧令牌立即失效

**自动登录令牌**
- 勾选「自动登录」签发7天令牌（rm声明）
- 未勾选维持24小时
- 前端同步本地有效期窗口

**邮箱验证闸门**
- 未验证邮箱用户403拒绝写操作
- 超管（is_admin）豁免闸门
- REQUIRE_EMAIL_VERIFICATION=false救援开关

**登录简化**
- 单步登录（密码+人机验证）直接返回token
- 不再发送登录邮箱验证码

**注册流程**
- 不再下发登录令牌，只返回{email_masked, verification_sent}
- 前端展示「去邮箱验证」面板（含重发）

**人机验证**
- 支持Turnstile、builtin、click、vaptcha四种provider
- 统一组件CaptchaField.vue
- login/register校验密码前先verify_captcha

**媒体分区**
- 公开区（/uploads）：已审核媒体
- 私有区（private_media）：待审/已屏蔽，需签名访问
- /api/media/{key}?exp=&sig= HMAC签名校验
- 审核翻转时自动搬区，旧地址立即失效

**图片净化**
- 所有上传经normalize_image()：魔数白名单 → 像素上限（25MP） → 剥EXIF → 长边2560缩放 → 重编码
- 动图只取首帧

**限流机制**
- 进程内滑动窗口，已覆盖：登录、注册、上传、发帖、改密、发邮件等
- BEHIND_PROXY=true时按X-Real-IP取真实IP

**运行面加固**
- backend以UID 10001运行，read_only + tmpfs + no-new-privileges
- frontend/edge只读根 + 内存临时目录
- 所有tmpfs显式写size=避免耗尽宿主机内存

**证书续期**
- certbot容器每12h renew
- edge容器每6h reload新证书
- healthcheck监控余期（不足10天报不健康）
