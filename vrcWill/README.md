# 糖霜世界 Sugar Frost

> 一款基于 VRChat 社交主题的**因果叙事解谜**网页游戏。
> 你是「观测者」——把被打散的聊天记录与回忆片段重新排序，修复（或亲手放开）一段段虚拟社交关系。

---

## 这是什么

玩家扮演"观测者"，通过拖拽重组 VRChat 用户之间发生过的聊天记录、事件片段的时间顺序，改变事件的因果逻辑。

**核心命题：**

> 当一段关系碎裂时，"修复"与"放手"，哪个才是温柔？

游戏不给出单一答案，而是让玩家在不同的排列组合中亲眼看见两种选择的后果。

## 快速开始

本项目**零依赖即可验证**（Node ≥ 22.6，利用原生 TypeScript type stripping）。

```bash
# 1. 穷举校验全部 12 关：证明每个设计结局都可达
node tools/verify-levels.ts

# 2. 运行引擎单元测试（34 项，无第三方依赖）
node --test tests/engine.test.ts

# 3. 启动前端开发服务器（需先安装依赖）
npm install
npm run dev
```

### 校验器输出示例

```
━━ 2-3 砂糖的诞生 ━━
  数据自检通过
  · 基础配置｜链长 7｜排列 120｜混沌 58 (48.3%)
      ✓ good         先问再说     得分 100/70  余量 +30
      ✓ bittersweet  迟到的恭喜    得分 100/60  余量 +40
      ✓ bad          质问        得分 100/55  余量 +45
      ✓ true         砂糖        得分 100/75  余量 +25
```

校验器会**枚举每个关卡的每一种合法排列**（最多 5040 种），确认：

1. 每个设计结局至少被一种排列命中；
2. 每个结局的最优排列与得分余量；
3. 混沌兜底占比是否合理；
4. 数据自洽性（ID 唯一、锚点正确、约束引用有效、阈值不超上限、各结局满分一致）。

## 核心概念速查

| 名词 | 含义 |
|---|---|
| **碎片 / Fragment** | 一条被打散的事件描述，是玩家操作的最小单位 |
| **因果链 / Chain** | 由碎片按顺序构成的完整故事序列 |
| **砂糖 / Satou** | VRChat 社区术语，指"比朋友更亲密、但未成为恋人"的关系形态 |
| **糖霜** | 凛建造的私人 World，也是本作标题；隐喻"美丽但易融的关系" |
| **观测者** | 玩家身份；能看见因果连线并重组顺序（第四章揭示为澪的残响） |
| **锚点碎片** | 灰色碎片，固定不可移动，代表确定的起点/终点 |
| **蝴蝶效应** | 跨角色交换碎片后触发的隐藏剧情 |
