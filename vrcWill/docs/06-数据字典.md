# 06 · 数据字典

> 本文枚举全部数据字段的类型、取值、约束与示例。
> 权威定义见 `src/lib/engine/types.ts`；本文为查阅用说明。

---

## 一、Fragment（碎片）

| 字段 | 类型 | 必填 | 取值 | 说明 |
|---|---|---|---|---|
| `id` | `string` | ✅ | `frag_<章>_<关>_<两位序号>` | 全局唯一。前缀必须与 `levelId` 匹配 |
| `levelId` | `string` | ✅ | `1-1` … `4-3` | 所属关卡 |
| `type` | `FragmentType` | ✅ | 见下表 | 碎片类型 |
| `character` | `CharacterId` | ✅ | 见下表 | 归属角色 |
| `text` | `string` | ✅ | 1–80 字 | 碎片正文（**唯一权威文案来源**） |
| `tags` | `string[]` | ✅ | 语义标签 | 用于提示系统、蝴蝶效应与埋点 |
| `draggable` | `boolean` | ✅ | — | 是否可拖拽 |
| `valence` | `number` | ✅ | -2 … +2 | 情感倾向，用于 Valence 指标 |
| `hidden` | `boolean` | ❌ | 默认 `false` | 是否默认隐藏 |
| `unlockedBy` | `string \| null` | ❌ | 见 §1.3 | 解锁条件（仅 `hidden: true` 时有意义） |
| `note` | `string` | ❌ | — | 设计备注，**不展示给玩家** |

### 1.1 FragmentType

| 值 | 中文 | 可拖拽 | 入链 |
|---|---|---|---|
| `white` | 白色 | ✅ | ✅ |
| `gray` | 灰色 | ❌ | ✅（仅首尾） |
| `gold` | 金色 | ✅ | ✅ |
| `red` | 红色 | 条件性 | ✅ |
| `blue` | 蓝色 | ❌ | ❌ |

### 1.2 CharacterId

| 值 | 中文 | 边框色 | 背景色 |
|---|---|---|---|
| `Mio` | 澪 | `#A8C4DD` | `#EEF3F8` |
| `Shiori` | 栞 | `#E0B08A` | `#FBF3EE` |
| `Rin` | 凛 | `#B9A8DD` | `#F3EEFB` |
| `Yu` | 悠 | `#A8DDBB` | `#EEFBF3` |
| `Observer` | 观测者 | `#BDBDBD` | `#F5F5F5` |
| `Echo` | 回声服务器 | `#8FA9A0` | `#F0F5F3` |
| `Narrator` | 旁白 | `#D8D8D2` | `#FAFAF7` |

### 1.3 unlockedBy 语法

| 语法 | 含义 | 示例 |
|---|---|---|
| `ending:<levelId>:<type>` | 通关某关的某类型结局 | `ending:1-3:good` |
| `endingType:<type>` | 任意关卡达成某类型结局 | `endingType:true` |
| `butterfly:<levelId>:<id>` | 触发某关的某蝴蝶效应 | `butterfly:3-3:A` |

### 1.4 示例

```json
{
  "id": "frag_2_3_04",
  "levelId": "2-3",
  "type": "gold",
  "character": "Shiori",
  "text": "【关键】B 说：「这是特别的人送的。」",
  "tags": ["reveal", "key"],
  "draggable": true,
  "valence": 1,
  "note": "金色碎片。与 A 的询问相邻时，会补全句子的主语。"
}
```

## 二、Constraint（约束）

| 字段 | 类型 | 必填 | 取值 | 说明 |
|---|---|---|---|---|
| `kind` | `ConstraintKind` | ✅ | `before` / `adjacent` / `position` / `block` / `group` | 约束种类 |
| `a` | `string` | 条件 | 碎片 ID | `before` / `adjacent` / `block` 使用 |
| `b` | `string` | 条件 | 碎片 ID | `before` / `adjacent` / `block` 使用 |
| `frag` | `string` | 条件 | 碎片 ID | `position` 使用 |
| `frags` | `string[]` | 条件 | 碎片 ID 数组 | `group` 使用 |
| `index` | `number` | 条件 | `0` … `chainLength-1` | `position` 使用，**0-based 完整链下标** |
| `weight` | `number` | ✅ | 正整数 | 正向为加分，在 `anti` 中为扣分 |

### 2.1 语义表

| kind | 必填字段 | 匹配条件 |
|---|---|---|
| `before` | `a`, `b` | `indexOf(a) < indexOf(b)` |
| `adjacent` | `a`, `b` | `abs(indexOf(a) - indexOf(b)) === 1` |
| `position` | `frag`, `index` | `indexOf(frag) === index` |
| `block` | `a`, `b` | 同 `adjacent`（仅用于 anti） |
| `group` | `frags` | `max(idx) - min(idx) + 1 === frags.length` |

### 2.2 缺失碎片处理

**任何涉及链中不存在碎片的约束，一律返回 `false`（不抛异常）。**

### 2.3 示例

```json
{ "kind": "before", "a": "frag_2_3_03", "b": "frag_2_3_02", "weight": 25 }
{ "kind": "adjacent", "a": "frag_2_3_06", "b": "frag_2_3_07", "weight": 35 }
{ "kind": "position", "frag": "frag_2_3_06", "index": 5, "weight": 20 }
{ "kind": "group", "frags": ["frag_2_3_02","frag_2_3_03","frag_2_3_04"], "weight": 25 }
```

## 三、Ending（结局）

| 字段 | 类型 | 必填 | 取值 | 说明 |
|---|---|---|---|---|
| `id` | `string` | ✅ | `<章>_<关>_<类型>` | 全局唯一，如 `2_3_good` |
| `levelId` | `string` | ✅ | — | 所属关卡 |
| `type` | `EndingType` | ✅ | 见下表 | 结局类型 |
| `title` | `string` | ✅ | ≤ 8 字 | 结局标题 |
| `threshold` | `number` | ✅ | 55 / 60 / 70 / 75 | 命中阈值（**≤ 约束权重之和**） |
| `valence` | `number` | ✅ | -2 … +2 | 情感倾向 |
| `constraints` | `Constraint[]` | ✅ | — | 正向约束（**权重之和必须 = 100**） |
| `anti` | `Constraint[]` | ✅ | 可为 `[]` | 负向约束 |
| `text` | `string` | ✅ | 60–200 字 | 结局正文，`\n\n` 分段 |
| `excerpt` | `string` | ✅ | ≤ 30 字 | 图鉴摘要 |
| `thumbnail` | `string` | ❌ | — | 缩略图路径，缺省用纯色渐变 |
| `requires` | `string[]` | ❌ | `["ending:1-3:good"]` | 前置解锁条件 |
| `hidden` | `boolean` | ❌ | 默认 `false` | 图鉴中默认显示为剪影 |
| `bondEffect` | `Record<CharacterId, number>` | ❌ | -30 … +30 | 羁绊值增减 |

### 3.1 EndingType

| 值 | 中文 | 阈值 | 渐变起 | 渐变止 |
|---|---|---|---|---|
| `good` | 修复 | 70 | `#F5D9A8` | `#FBF6EE` |
| `bittersweet` | 遗憾 | 60 | `#9FB3C8` | `#EEF2F5` |
| `bad` | 破碎 | 55 | `#7A3B3B` | `#2A2A2E` |
| `true` | 真相 | 75 | `#F5D9A8` | `#A8C4DD` |
| `chaos` | 混沌 | 999 | `#3A3A3E` | `#3A3A3E` |

### 3.2 铁律

> **同一关卡内，所有 `endings[].constraints` 的权重之和必须一致（本作统一为 100）。**

原因见 `docs/02-判定引擎规格.md` §6.1。由 `tools/verify-levels.ts` 强制校验。

## 四、Butterfly（蝴蝶效应）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | `string` | ✅ | `<关卡>:<字母>`，如 `3-3:A` |
| `requires` | `Constraint[]` | ✅ | 全部满足才触发 |
| `unlocks` | `string[]` | ✅ | 解锁的碎片 ID |
| `revealText` | `string` | ✅ | 触发时展示的演出文本 |

```json
{
  "id": "3-3:A",
  "requires": [
    { "kind": "adjacent", "a": "frag_3_3_02", "b": "frag_3_3_03", "weight": 1 },
    { "kind": "before", "a": "frag_3_3_03", "b": "frag_3_3_05", "weight": 1 }
  ],
  "unlocks": ["frag_3_3_10"],
  "revealText": "把「澪站在人群外」和「悠指著她问」放在一起……"
}
```

## 七、Level（关卡）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | `string` | ✅ | 如 `2-3` |
| `title` | `string` | ✅ | 关卡标题 |
| `chapter` | `number` | ✅ | 1–4 |
| `order` | `number` | ✅ | 章内序号 1–3 |
| `epigraph` | `string` | ✅ | 章首语（非章首关为 `""`） |
| `intro` | `string` | ✅ | 开场文本 |

| `behindTheScenes` | `string` | ✅ | 集齐全部结局后解锁的幕后注释 |

## 八、JudgeResult（判定结果）

| 字段 | 类型 | 说明 |
|---|---|---|
| `ending` | `Ending` | 命中结局 |
| `isChaos` | `boolean` | 是否混沌兜底 |
| `score` | `number` | 命中结局得分 |
| `coherence` | `number` | 0–100 连贯度 |
| `valence` | `number` | -100 … +100 情感走向 |
| `evaluations` | `EndingEvaluation[]` | 全部结局的评估明细 |
| `runnerUp` | `EndingEvaluation \| undefined` | 次优结局 |

**EndingEvaluation**

| 字段 | 类型 | 说明 |
|---|---|---|
| `endingId` | `string` | 结局 ID |
| `score` / `threshold` | `number` | 得分与阈值 |
| `qualified` | `boolean` | 是否命中（含前置检查） |
| `unlocked` | `boolean` | 前置是否满足 |
| `trace` | `ConstraintTrace[]` | 逐条约束的命中轨迹（调试用） |

## 十、字段约束汇总（供校验器使用）

| 约束 | 检查位置 |
|---|---|
| 碎片 ID 全局唯一 | 测试 + 校验器 |
| 碎片 ID 前缀 = `frag_<levelId 下划线>` | 测试 |
| 锚点存在且 `type === 'gray'` | 校验器 |
| `initialOrder[0] === anchors.first` | 校验器 |
| `initialOrder[last] === anchors.last` | 校验器 |
| 可动区间内无灰色碎片 | 校验器 |
| 约束引用的碎片必须存在于本关 | 校验器 |
| `position.index` 在 `[0, chainLength-1]` 内 | 校验器 |
| `threshold ≤ Σ(constraints.weight)` | 校验器 |
| 同关卡各结局 `Σ(constraints.weight)` 相等 | 校验器 **（铁律）** |
| 蓝色碎片 `draggable === false` 且不在链中 | 测试 |
| `text.length ∈ (0, 80]` | 测试 |
| 结局 `text` / `excerpt` 非空 | 测试 |
