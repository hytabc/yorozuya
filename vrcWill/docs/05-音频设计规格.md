# 05 · 音频设计规格

> 音频为 P2 优先级。本文定义音频清单、触发点、混音分层、格式与体积预算。

---

## 一、整体听感

- **基调**：低音量环境电子乐，参考 VRChat 夜晚世界中的氛围音乐。
- **关键词**：雪、空旷、呼吸、低频脉冲。
- **避免**：旋律性过强的配乐、激烈打击乐、明显"游戏化"的提示音。
- **原则**：音乐在玩家**不刻意听**的时候才存在。任何音效都不得打断阅读。

---

## 二、混音分层

三条独立总线，音量可分别控制（设置页）：

| 总线 | 默认音量 | 内容 |
|---|---|---|
| `master` | 0.7 | 总输出 |
| `sfx` | 0.8 | 交互音效 |
| `music` | 0.5 | 背景音乐与环境音 |

**闪避（ducking）**：结局文本显示期间，`music` 自动降至 40%，`sfx` 保持不变。文本出现完毕 1s 后恢复。

**静音阈值**：任何单次音效峰值不得超过 -6dBFS，避免刺耳。

---

## 三、音效清单

### 3.1 交互音效（sfx）

| ID | 触发点 | 描述 | 时长 | 音量 |
|---|---|---|---|---|
| `sfx.pick` | 碎片被拿起 | 轻微纸张摩擦 | 120ms | 0.35 |
| `sfx.place` | 碎片落位 | 清脆的"咔嗒" | 90ms | 0.45 |
| `sfx.place_mio` | 澪的碎片落位 | 同上，音高 +2 半音 | 90ms | 0.45 |
| `sfx.place_shiori` | 栞的碎片落位 | 同上，音高 +4 半音 | 90ms | 0.45 |
| `sfx.place_rin` | 凛的碎片落位 | 同上，音高 −2 半音 | 90ms | 0.45 |
| `sfx.place_yu` | 悠的碎片落位 | 同上，音高 +6 半音 | 90ms | 0.45 |
| `sfx.reject` | 非法落点（拖向首尾） | 低沉的钝响 | 150ms | 0.3 |
| `sfx.locked` | 尝试拖拽灰色碎片 | 极轻的木质敲击 | 80ms | 0.25 |
| `sfx.undo` | 撤销 | 反向的纸张摩擦 | 140ms | 0.3 |
| `sfx.hover` | 卡片悬停（仅首次） | 极轻的电子滴 | 40ms | 0.12 |
| `sfx.butterfly` | 蝴蝶效应触发 | 玻璃风铃散开 | 1200ms | 0.5 |
| `sfx.unlock` | 蓝色碎片解锁 | 单音铃（上行） | 800ms | 0.4 |
| `sfx.meter_glow` | 指标达 80 | 极轻的低频脉冲 | 400ms | 0.2 |

> **音高差异化**：通过同一采样变调实现，而不是四套独立音效。这样体积更小、听感更统一。

**设计理由**：玩家闭着眼睛也能听出"我刚放下的是谁的碎片"。这是在不增加视觉负担的前提下强化角色辨识度的手段。

### 3.2 结局音效

| ID | 结局类型 | 描述 | 时长 |
|---|---|---|---|
| `sfx.ending_good` | `good` | 温暖钢琴和弦，缓慢上行 | 3000ms |
| `sfx.ending_bittersweet` | `bittersweet` | 单音铃，余音很长 | 3500ms |
| `sfx.ending_bad` | `bad` | 低频嗡鸣，缓慢下沉 | 3000ms |
| `sfx.ending_true` | `true` | 双声部合唱（女声 + 低频） | 5000ms |
| `sfx.ending_chaos` | `chaos` | 白噪 + 短促静电 | 1500ms |

### 3.3 界面音效

| ID | 触发点 | 描述 |
|---|---|---|
| `sfx.ui_click` | 按钮点击 | 极轻的木质"嗒" |
| `sfx.ui_open` | 抽屉/覆盖层打开 | 气流声（上行） |
| `sfx.ui_close` | 关闭 | 气流声（下行） |
| `sfx.chapter_enter` | 进入章节 | 雪花飘落白噪，2s |
| `sfx.level_enter` | 进入关卡 | 短促的"回声"开场音，1.5s |

## 四、背景音乐

| ID | 场景 | 描述 | 时长 | 循环 |
|---|---|---|---|---|
| `bgm.title` | 标题页 | 稀疏的钢琴单音 + 低频 pad | 90s | ✅ |
| `bgm.ch1` | 第一章 · 初识 | 明亮、略带期待的空灵电子 | 120s | ✅ |
| `bgm.ch2` | 第二章 · 砂糖 | 温暖、暧昧、缓慢推进 | 120s | ✅ |
| `bgm.ch3` | 第三章 · 裂痕 | 冷、稀疏、留白很多 | 120s | ✅ |
| `bgm.ch4` | 第四章 · 重逢 | 前段压抑，后段逐渐开阔 | 150s | ✅ |
| `bgm.ending_good` | good 结局 | 温暖钢琴独奏 | 60s | ❌ |
| `bgm.ending_bad` | bad 结局 | 低频 drone | 60s | ❌ |
| `bgm.theme` | 真结局 | 主题曲《今晚我依然登入》 | 150s | ❌ |

**章节过渡**：章节切换时，旧 BGM 在 1.5s 内淡出，新 BGM 在 2s 内淡入，中间叠加 1.5s 的雪花白噪作为过渡。

## 五、语音

**本作不包含任何配音。**

理由：与"文字解谜"的定位一致；保持玩家的想象空间；降低制作成本与体积。

蓝色碎片（内心独白）以文字形式呈现，不配音。

---

## 六、格式与体积预算

| 项目 | 规格 |
|---|---|
| 主格式 | `.ogg`（Vorbis，q5） |
| 兼容回退 | `.mp3`（128kbps CBR） |
| 采样率 | 44.1kHz |
| 声道 | 单声道（音效）/ 立体声（BGM） |
| 加载策略 | 音效预加载；BGM 按章节懒加载 |
| 体积预算 | 音效总计 < 1.5MB；BGM 总计 < 6.5MB；**总计 < 8MB** |

**加载优先级**：

1. 首屏必需（`sfx.ui_click`、`bgm.title`）→ 同步预加载
2. 交互音效 → 进入关卡时预加载
3. 结局音效 → 首次提交判定时预加载
4. 章节 BGM → 进入章节页时预加载

## 七、实现约定

### 7.1 音频总线

```ts
interface AudioBus {
  play(id: string, opts?: { volume?: number; rate?: number }): void;
  loop(id: string, opts?: { fadeIn?: number }): void;
  stop(id: string, opts?: { fadeOut?: number }): void;
  setBusVolume(bus: 'master' | 'sfx' | 'music', v: number): void;
  setDucking(on: boolean): void;
}
```

### 7.2 关键实现要求

1. **必须响应设置变化**：音量、静音、减少动效（减少动效时保留音频，只去掉视觉）。
2. **必须处理自动播放限制**：浏览器要求用户交互后才能播放音频。首次点击任意位置时初始化 `AudioContext`。
3. **同一音效连续触发需节流**：最小间隔 60ms，避免快速拖拽时音效叠加刺耳。
4. **页面隐藏时暂停**：`document.visibilitychange` → 暂停 BGM。
5. **不支持时静默降级**：任何音频错误不得影响游戏流程。

### 7.3 音效命名规范

```
sfx.<domain>_<action>[_<variant>]
bgm.<scene>
```

例：`sfx.place_shiori`、`bgm.ch3`。

- 一份与本文 ID 一一对应的清单

## 九、备选方案（若音频资源无法产出）

若音频方案被砍，游戏体验**不受致命影响**（音频为 P2）。降级顺序：

1. 保留：`sfx.place`（落位反馈）、`sfx.ending_*`（结局情绪）
2. 保留：`bgm.ch1`–`bgm.ch4`（氛围）
3. 可砍：`sfx.hover`、`sfx.meter_glow`、`sfx.ui_*`
4. 可砍：全部变调版本（用同一个音效替代）

删除音频只需从资源清单移除，代码中的 `AudioBus` 调用会自动静默降级。
