# 04 · 美术与视觉规格

> 本文定义 Design Token、色板、字体、间距、圆角、阴影与动效曲线。
> 所有值以 CSS 自定义属性形式实现于 `src/lib/styles/tokens.css`。

---

## 一、视觉基调

- **整体**：低饱和度冷色调为主，辅以暖色点缀，呼应 VRChat 夜晚世界的氛围。
- **关键词**：雪、夜晚、纸、玻璃、低语。
- **避免**：高饱和霓虹、赛博朋克、强对比色块、圆润可爱的卡通感。
- **原则**：UI 永远退到内容之后。碎片卡片是唯一的主角。

## 三、字体

### 3.1 字族

```css
--font-sans: "Noto Sans SC", "Source Han Sans SC", "PingFang SC",
             "Microsoft YaHei", system-ui, sans-serif;
--font-serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC",
              "SimSun", serif;
```

| 用途 | 字族 | 理由 |
|---|---|---|
| UI、碎片正文 | `--font-sans` | 清晰、日常感 |
| 结局正文、章首语 | `--font-serif` | 与"回忆/叙事"的语境呼应 |
| 数字、ID | `--font-sans` + `font-variant-numeric: tabular-nums` | 对齐 |

### 3.2 字阶

| Token | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `--fs-display` | 32px | 1.35 | 500 | 结局标题 |
| `--fs-h1` | 24px | 1.4 | 500 | 关卡标题、章节标题 |
| `--fs-h2` | 19px | 1.45 | 500 | 区块标题 |
| `--fs-body` | 16px | 1.65 | 400 | 碎片正文 |
| `--fs-body-sm` | 14px | 1.6 | 400 | 辅助正文 |
| `--fs-caption` | 12px | 1.5 | 400 | 标签、序号 |

**字号设置**（设置页）：`small` × 0.9 / `medium` × 1.0 / `large` × 1.15，作用于 `--fs-body` 与 `--fs-body-sm`。

### 3.3 排版细节

- 中英混排时，中英文之间自动插入 1/4 空格（使用 `text-spacing-trim` 或手动 span）。
- 正文行长控制在 **28–38 个汉字**（约 `max-width: 34em`）。
- 段落间距 = `1.2 × 行高`。
- 对话使用「」，不用 ""。

## 六、阴影

```css
--sh-1: 0 1px 2px rgba(0,0,0,.06);                  /* 静置 */
--sh-2: 0 4px 12px rgba(0,0,0,.10);                 /* 悬停 */
--sh-3: 0 12px 28px rgba(0,0,0,.18);                /* 拖拽中 */
--sh-glow: 0 0 12px rgba(123,167,199,.45);          /* 指标达阈值 */
--sh-inset: inset 0 1px 0 rgba(255,255,255,.04);    /* 内描边高光 */
```

> 本作不使用强烈阴影。所有阴影应"像纸落在纸上"，而不是"像卡片浮在空中"。

## 七、质感

### 7.1 纸张噪点

碎片卡片叠加一层极淡噪点，模拟纸质。

```css
.fragment-card::after {
  content: "";
  position: absolute;
  inset: 0;
  border-radius: inherit;
  background-image: url("/textures/noise.png");
  opacity: .04;
  pointer-events: none;
  mix-blend-mode: multiply;
}
```

- `noise.png`：128×128 灰度噪点，无缝平铺，体积 < 8KB。
- 不透明度上限 **0.04**——超过就会显脏。

### 7.2 雪花粒子（背景）

- 60 个粒子，尺寸 1–2px，随机不透明度 0.15–0.4。
- 下落速度 8–20px/s，横向漂移 ±6px/s。
- 使用 `<canvas>` 渲染，`requestAnimationFrame` 驱动。
- 「减少动效」开启时完全停用。

### 7.3 玻璃质感（结局覆盖层）

```css
backdrop-filter: blur(12px) saturate(1.1);
```

## 八、动效

### 8.1 缓动曲线

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.2,.8,.3,1)` | 进入、落位 |
| `--ease-in-out` | `cubic-bezier(.4,0,.2,1)` | 通用过渡 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 回弹 |
| `--ease-linear` | `linear` | 指标条宽度（连续变化） |

### 8.2 时长

| Token | 值 | 用途 |
|---|---|---|
| `--dur-instant` | 100ms | 悬停色变 |
| `--dur-fast` | 180ms | 落位、按钮按下 |
| `--dur-base` | 280ms | 抽屉开合、淡入 |
| `--dur-slow` | 500ms | 结局标题、章节过渡 |
| `--dur-xslow` | 900ms | 全屏演出 |

**减少动效开启时**：全部时长 × 0。

### 8.3 关键动效定义

| 名称 | 定义 |
|---|---|
| **落定** | `transform: translateY(-6px) scale(1.02) → none`，180ms `--ease-out` |
| **回弹** | `translateX(0 → -8px → 8px → -4px → 0)`，220ms |
| **抖动** | 同上但幅度 8px，120ms |
| **结局标题** | `opacity 0→1` + `translateY(12px → 0)`，500ms `--ease-out` |
| **指标脉冲** | `box-shadow` 呼吸 2 次，600ms |
| **涟漪** | 径向渐变从点击点扩散到全屏，800ms |
| **雪花汇聚** | 60 个粒子向中心汇聚并淡出，1200ms |

| 资源 | 规格 | 数量 | 体积预算 |
|---|---|---|---|
| `noise.png` | 128×128 灰度，无缝 | 1 | < 8KB |

## 十一、无障碍视觉

| 模式 | 调整 |
|---|---|
| 色盲模式 | 边框加粗至 2px；形状标识放大 1.4×；提高明度对比 |
| 高对比度 | `--text-primary` → `#FFFFFF`；`--bg-base` → `#000000`；边框 → `#FFFFFF` |
| 减少动效 | 关闭雪花粒子、涟漪、汇聚动画；过渡 0ms |

## 十二、视觉检查清单

- [ ] 所有文字对比度 ≥ 4.5:1（大字号 ≥ 3:1）
- [ ] 角色可仅凭形状区分（不依赖颜色）
- [ ] 结局类型可仅凭文字标签区分
- [ ] 噪点不透明度 ≤ 0.04
- [ ] 无纯黑纯白（除高对比度模式）
- [ ] 正文行长 ≤ 38 汉字
- [ ] 所有过渡使用统一缓动 token
- [ ] 减少动效模式下无动画残留
- [ ] 1280×720 与 2560×1440 下布局均无溢出
- [ ] 首包 < 300KB（gzip）
