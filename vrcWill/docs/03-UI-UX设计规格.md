**尺寸约定：**

| 元素 | 尺寸 |
|---|---|
| 因果链区域宽度 | `min(560px, 48vw)` |
| 碎片卡片 | 宽 100%，高自适应（min 64px） |
| 卡片内边距 | 16px 20px |
| 卡片间距 | 10px |
| 槽位占位高度 | 64px |
| 侧栏（碎片池 + 独白） | 320px |
| 底部操作栏 | 高 72px，吸底 |

### 3.2 移动端（< 768px）

- 单列纵向布局，碎片池折叠为顶部横向滚动条。
- 底部固定「让因果稳定」按钮（高 56px，全宽）。
- 指标条压缩为细条（高 4px），数值文字缩小到 11px。
- 拖拽需长按 200ms 激活。

### 3.3 响应式断点

| 断点 | 布局 | 侧栏 |
|---|---|---|
| ≥ 1280px | 双列（链 + 侧栏） | 展开 320px |
| 1024–1279px | 双列 | 展开 280px |
| 768–1023px | 单列 + 侧栏抽屉 | 折叠 |
| < 768px | 单列 + 底部固定操作栏 | 抽屉（全屏） |

## 四、碎片卡片规格

### 4.1 结构

```html
<article class="fragment-card" data-type="gold" data-character="Shiori"
         draggable="true" tabindex="0" role="listitem"
         aria-label="碎片 3，共 5 枚。B 换了一个新 Avatar。">
  <span class="card-index">3</span>          <!-- 序号角标 -->
  <span class="card-shape" />                 <!-- 角色形状标识 -->
  <p class="card-text">B 换了一个新 Avatar。</p>
  <span class="card-lock" />                  <!-- 仅灰色碎片 -->
</article>
```

### 4.2 状态样式

| 状态 | 表现 |
|---|---|
| `default` | 背景 = 角色 bg 色；1px 边框 = 角色主色；圆角 12px；阴影 `0 1px 2px rgba(0,0,0,.06)` |
| `hover` | 阴影升为 `0 4px 12px rgba(0,0,0,.10)`；`translateY(-1px)`；160ms 过渡 |
| `focus-visible` | 外描边 `2px solid #7BA7C7`，offset 2px |
| `dragging` | `opacity: .6`；`transform: scale(1.02)`；阴影 `0 12px 28px rgba(0,0,0,.18)`；`cursor: grabbing` |
| `drag-over` | 上方或下方显示 2px 插入指示线（角色主色） |
| `locked`（灰色） | `cursor: not-allowed`；`filter: brightness(.96)`；显示锁形角标 |
| `red-locked` | 暗红边框；`filter: saturate(.5)`；裂纹纹理 |
| `red-unlocked` | 恢复正常饱和度；边框保持暗红 |
| `shaking`（非法操作） | 水平抖动 8px，120ms |
| `disabled` | `opacity: .5`；`pointer-events: none` |

### 4.3 卡片内文字规范

| 项目 | 值 |
|---|---|
| 字号 | `clamp(14px, 1.5vw, 16px)` |
| 行高 | 1.65 |
| 字重 | 400 |
| 最大字符数 | 60 字（超出由数据层保证） |
| 对话标点 | 使用「」而非"" |

## 五、指标条规格

### 5.1 连贯度 Coherence

```
┌──────────────────────────────────────────┐
│ 因果连贯度                    70         │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░  │
└──────────────────────────────────────────┘
```

| 属性 | 值 |
|---|---|
| 轨道色 | `rgba(123,167,199,.15)` |
| 填充色 | `#7BA7C7` |
| 高度 | 6px（桌面）/ 4px（移动） |
| 圆角 | 3px |
| 过渡 | `width 400ms cubic-bezier(.2,.8,.3,1)` |
| ≥ 80 时 | 填充加 `box-shadow: 0 0 8px rgba(123,167,199,.6)` |

### 5.2 情感走向 Valence

- 中点为 0，向左为负（疏离），向右为正（靠近）。
- 填充从中心向两侧延伸。
- 正值填充 `#E0B08A`（暖橙）；负值填充 `#8FA9A0`（冷青）。
- 数值文字带正负号。

## 六、结局覆盖层规格

### 6.1 演出时序

| 时刻 | 事件 |
|---|---|
| 0ms | 全屏遮罩 `opacity: 0 → 1`（300ms） |
| 300ms | 背景渐变淡入（600ms），按结局类型配色 |
| 500ms | 结局类型徽章淡入（300ms） |
| 700ms | 结局标题淡入 + 上移 12px（500ms） |
| 1000ms | 结局正文逐段淡入（每段 200ms 间隔） |
| 正文结束 + 400ms | 操作按钮淡入（300ms） |

**减少动效开启时**：全部压缩为 0ms，直接切换。

### 6.2 结局类型徽章

| 类型 | 文案 | 色彩 |
|---|---|---|
| `good` | 修复 | `#F5D9A8` |
| `bittersweet` | 遗憾 | `#9FB3C8` |
| `bad` | 破碎 | `#7A3B3B` |
| `true` | 真相 | 暖金 + 冷蓝双色 |
| `chaos` | 混沌 | `#3A3A3E` |

### 6.3 操作按钮

| 按钮 | 样式 | 行为 |
|---|---|---|
| 保留此结局 | 主按钮（实心） | 写档、结算、解锁 |
| 重新排列 | 次按钮（描边） | 回到 arranging |

## 七、交互态清单

每个可交互组件必须实现以下状态（缺一不可）：

| 状态 | 说明 |
|---|---|
| `default` | 默认 |
| `hover` | 悬停（触屏设备跳过） |
| `focus-visible` | 键盘聚焦 |
| `active` | 按下 |
| `disabled` | 禁用 |
| `loading` | 加载中（仅数据依赖组件） |
| `error` | 错误（仅数据依赖组件） |

## 八、无障碍规格

### 8.1 键盘可达性

**要求：不使用鼠标即可完成全部核心操作。**

| 操作 | 按键 |
|---|---|
| 遍历交互元素 | `Tab` / `Shift+Tab` |
| 移动碎片 | `Ctrl/⌘ + ↑/↓` |
| 移至可动区间首/末 | `Ctrl/⌘ + Home/End` |
| 提交 | `Enter` |
| 撤销 | `Ctrl/⌘ + Z` |
| 打开提示 | `?` 或 `Shift + /` |
| 关闭抽屉/覆盖层 | `Esc` |

### 8.2 屏幕阅读器

- 碎片卡片使用 `role="listitem"`，外层 `role="list"`。
- 焦点变化时通过 `aria-live="polite"` 播报：「碎片 3，共 5 枚。『B 换了一个新 Avatar』。」
- 移动碎片后播报：「已移动到第 2 位。」
- 指标变化通过 `aria-live="polite"` 节流播报（最多每 2s 一次）：「因果连贯度 70，已经稳定。」
- 结局覆盖层使用 `role="dialog" aria-modal="true"`，打开时聚焦标题，`Esc` 不可关闭（必须做出选择）。

### 8.3 色彩无障碍

- 角色区分**不只依赖颜色**：每个角色有专属形状标识（圆/三角/方/星）。
- 提供「色盲模式」开关：强化形状对比，边框加粗到 2px。
- 结局类型徽章同时显示文字标签，不只用颜色。

### 8.4 对比度

- 正文文字对比度 ≥ 4.5:1（WCAG AA）。
- 大字号标题 ≥ 3:1。
- 「高对比度」开关：正文改用 `#1A1A1A`，背景提亮到 `#FFFFFF`。

### 8.5 动效

- 提供「减少动效」开关，同时尊重 `prefers-reduced-motion`。
- 开启后：所有过渡 0ms，拖拽无缩放，结局直接切换，关闭雪花粒子。

## 十一、文案规范（UI 层）

| 场景 | 规范 | 示例 |
|---|---|---|
| 按钮 | 动词短语，≤ 6 字 | 「让因果稳定」「重新排列」 |
| 提示 | 陈述句，不用感叹号 | 「因果还不稳定。」 |
| 错误 | 说明原因 + 给出出路 | 「关卡数据加载失败。请检查网络后重试。」 |
| 空态 | 温和，不指责玩家 | 「还没有见过任何结局。」 |
| 标点 | 对话用「」；省略用「……」 | — |
| 人称 | 对玩家称「你」，但尽量少用 | — |
